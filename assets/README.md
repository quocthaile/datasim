# Application assets

`datasim-mark.svg` is an original project-owned monochrome Datasim mark created
for this workbench. It contains no third-party artwork or font data. It is
embedded by `viewer.qrc` at the stable path `:/datasim/branding/datasim-mark.svg`.
No external license or redistribution claim is made; repository licensing
remains an owner decision.

The resource bytes are included in `DATASIM_SOURCE_SHA256` by the CMake source
fingerprint policy. User datasheets remain external local files. Synthetic PDF
fixtures remain under `tests/fixtures/`.
